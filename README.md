# Demo: Generación de contenido y campañas

Industria: Retail y Consumo Masivo  
Escenario: Marketing y contenido  
Solución Microsoft: Microsoft 365 Copilot + Azure OpenAI  
Outcome esperado: Aceleración de campañas y consistencia de marca.

## Incluye

- Brief de campaña editable.
- 6 prompts en español para Microsoft 365 Copilot.
- Concepto de campaña.
- 3 posteos para redes.
- Asunto y preheader de email.
- Variantes por canal: LinkedIn, app push y banner web.
- Revisión de tono y marca.
- Guion de demo.

## Nota técnica

Frontend estático para GitHub Pages. Los outputs están precargados para mostrar el flujo de valor esperado.
